# hojun-app-teardown

## 目的

快速理解产品本质，识别核心价值、增长逻辑、商业模式与关键假设。

本分析报告必须能回答：

- 这是什么产品？
- 为谁服务？
- 解决什么问题？
- 为什么用户会持续使用？
- 如何增长？
- 如何赚钱？
- 最大风险在哪里？

---

## 输入格式

```
<App 名称> <App Store 或 Google Play 链接> [--focus <重点章节>] [--vs <对比 App 名>]
```

- `--focus`（可选）：指定深入章节，如 `--focus 商业模式`
- `--vs`（可选）：并行拉取对比 App，报告末尾加对比表

---

## 报告结构

> **写作顺序**：先写第 1-8 章 + 必要的可选章，最后回头写顶部（一句锐评 / 核心结论速览 / 数据速览）。不要边读边填顶部。

### 一句锐评

一句话给出最强判断，不留余地。

### 核心结论速览

控制 300-500 字。

- **一句话定位**：摘抄第 1 章一句话定位
- **主要目标用户群体**：句式"为完成 [JTBD top job] 的 [核心用户画像]"
- **产品核心假设**：作者最关键的 1-2 条不证之物
- **产品核心赌注**：3-4 个最关键的产品 / 商业 / 增长赌注，每条编号 + 含关键时间 + 关键数据（第 8 章可证伪预测会按编号一一配对）
- **主要风险**：3 条最严重负面信号，分号分隔
- **结合第 8 章的总结**：产品本质 + 一句话最终判断 + 综合评分

> 不做解释，解释推到对应章节。

### 第 8 章 — 最终判断

#### 品类成熟度

判断 App 所在品类的生命周期阶段，给出支撑信号与战术含义：

- 阶段：开拓期 / 成长期 / 成熟期 / 衰退期（择一）
- 支撑信号（1-2 条，含来源）
- 战术含义（1 句，该阶段意味着什么策略路径）

#### 竞争定位象限

自选 2 个最能揭示竞争格局的轴，绘制 2×2 文字版象限，标出该 App 与主要竞品位置。两句说明：该 App 落在哪个象限，意味着什么。

- moat 类型（从 Brand / Data / Network Effects / Switching Cost / Scale / IP / Geographic / Habit 中识别 1-2 个）

- 防御性（1 句：竞品想模仿要付出什么代价？）

### 7 个可选补充章节

数据丰富度足够（至少 2 个实质性数据点）才写，否则跳过，不写占位段。

1. **国际化策略** — 多语言支持、出海重点市场、本地化程度
2. **创始人媒体形象** — 公开发言、播客 / 访谈
3. **关键人才信号** — 近期关键岗位招聘（LinkedIn / Indeed）
4. **下一步预测** — 基于现有信号推断路线图或下一动作
5. **平台政策风险** — App Store / Google Play 合规史、IAP 规则
6. **关键事件黑天鹅** — 下架、泄露、媒体危机复盘
7. **同名混淆风险** — 商标争议、同名 App 竞争

## 硬约束

1. **凡数据有源**：找不到的数字标"无公开数据"，不猜成事实。
2. **不输出无源关键指标**：DAU / MAU / 收入 / 用户规模 / 增长率，没有明确来源就不写。
3. **观点要支撑**：没有证据的判断标"推测"，不写成确定结论。
4. **优先 S 级信源**：降级时在文中注明引用等级。
5. **不放大信号**：1 条 Reddit 帖子不写成"用户普遍反映"。
6. **每个洞察至少 1 个具体例子**：数字 / 引言 / 事件三选一。
7. **不情绪化评价**：砍"垃圾 / 智商税 / 优秀 / 颠覆 / 现象级"类标签词。
8. **分析不罗列**：功能不只列名字，必答"为什么存在、解决什么、对增长 / 收入有什么作用"。
9. **基础假设只列不展开**：列出作者的不证之物，不替它论证为什么前提成立。
10. **原文引用必须存在**：第 4 章用户反馈正负各 ≥ 3 条原文。
11. **中文正文，英文术语**：代码 / 变量 / 文件路径 / 框架名称用英文。

## 写作风格

**必须遵守：**

- 冷静
- 简洁（短句多，长句少；"通过 / 借助 / 在 X 上 / 凭借"能砍就砍）
- 直白（不用"作者认为 / X 在评论里指出"，直接说 App 干了什么）
- 犀利（一个判断要么明确支持要么明确反对，不骑墙）
- 结论优先
- 基于事实推断
- 朗读关（每段默念一遍，读起来卡的地方整句重写）

**避免：**

- 套话 / 空话 / 互联网黑话
- 过度赞美 / 过度批评
- 翻译腔（"让我们一起 / 提供支持 / 做出选择 / 拥有 X 的能力 / 进行 X"）
- 自我修辞（"这一刀 / 锋利（作元描述）/ 钉死 / 砸实 / 砍掉"作为段落修辞）
- 长篇背景介绍
- 学术腔（"综合考量 / 在某种意义上 / 具有重要意义"）
