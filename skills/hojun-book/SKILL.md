# hojun-book: 走查 + 拆书

输入一本书，输出两份东西：走查 + 拆书。

走查铺面，让读者"知道这本书在讲什么"。
拆书钻骨，让读者"看穿作者怎么写这本书"。

两部分合并为一个 Markdown 文件交付。

---

## 第一部分：走查（4 模块）

### 模块 1：书籍与作者背景

要写的字段：

- 出版时间 + 首次出版的国家/语言
- 作者基本信息（生卒、国籍、主要身份）
- 创作时代背景：作者在什么社会、思潮、技术环境里写的？跟什么对话？反对什么？延续什么？
- 该书在作者作品序列里的位置（成名作 / 转型 / 晚期总结 / 被忽视的早作）
- 该书在其领域内的位置（开山 / 经典综述 / 反叛 / 商业畅销）

每条 1-2 句话。挑跟书内容直接相关的背景说，不要维基百科式罗列。

### 模块 2：速读总结（三层级）

**层级一：一句话核心**（≤ 30 字）— 锋利、可立、能 quote。

**层级二：段落级速读**（200-350 字）— 短书评的内核。讲清：在答什么问题、用什么角度回答、得出什么结论、为什么重要。

**层级三：3 个 takeaways**（每条 1-2 句）— 读者带走的最实用 3 件事。避免空话，具体到能 quote。

### 模块 3：章节拆解（逐章节）

每章按下面格式交付：

```
### 第 N 章：[章节标题]

**这一章讲什么**（2-3 句）
[作者论证、讨论、推进的内容]

**关键观点 / 核心句**（1-3 条 bullet）
- [观点 1 — 能 quote 最好]
- [观点 2]

**原话金句**（2-5 条，作者本人原话）
- > "[原书 quote 1]" — 第 X 页 / 第 X 节
- > "[原书 quote 2]" — 第 X 页 / 第 X 节

**一句话点评**
[有立场的判断：在结构里的作用 / 你对它的判断]
```

规则：

- 不跳章节，每章都过
- 原话金句必须是作者本人句子（译本标译者 + 用译本原文）
- 每章原话金句 2-5 条之间，少于 2 → 你没读够；多于 5 → 抄全章了
- 点评要有立场，"讲得很好"、"很重要"这类软话不要
- 章节超过 20 章可合并相邻章（如"第 5-7 章：进化的证据"），但不许跳
- 无明确章节的书（如哲学经典），按论证段落自分，标"段一/段二"

### 模块 4：思考与意义

四个字段：

- **重新看什么？**（1-2 条）—— 读完这本书后，哪一类问题不会再用原来的方式看？
- **对什么人 / 什么场景最值得读？**（1 条）—— 具体到职业 / 阶段 / 困惑，不要"所有人"
- **作者没写但能引申到哪儿？**（1-2 条）—— 把作者的工具借出来用到他没去过的地方（这里只指方向，预测留到拆书第 6 段）
- **配合谁读？**（可选 1 条）—— 互补或对立的书 1-2 本

## 第二部分：拆书（6 段）

拆书的目的不是替读者再读一遍。是把作者**怎么想问题、怎么搭论证、怎么收结论**这套思路抽出来摆好。下次读者遇到作者没写过的新场景，能拿来直接用。

六段递进。前五段先把作者的内核拆开，第六段把内核练成可外推的工具。

### 第 1 段：作者要解决的真问题

每本书表面写一个题目，骨子里在回应一个具体的问题。**题目跟问题不是一回事**。

例如《国富论》题目是"国家怎么富起来"，问题其实是"为什么自由市场比重商主义更有效"。区分这两层很重要——后者才是作者真正下笔的方向。

要拎出三件事：

1. **题面**：作者表面在讨论什么主题
2. **真问题**：剥掉题面之后，作者实际在尝试回答什么
3. **写作触发**：作者为什么是现在、是他来写。他对什么现象感到不耐烦？在反对哪一派？想纠正读者哪个误解？

写作触发是最难抓也最容易漏的一环。一本好书的作者，往往是带着"再不写就会被错过"的迫切感动笔的。读导言、找作者反复回到的那个点，触发就在里面。

**自检**：把这段写完，去掉书名，能套到同领域其他书上吗？能套 → 抽象过头，重写。

### 第 2 段：作者的隐含前提

每本书都立在几条**不被讨论的前提**上。作者不证明它们，但整本书的论证都靠它们撑着。

找前提的两个问题：

- 这本书里**哪些立场是默认成立的**？读者只要质疑这个立场，作者就会判定读者外行
- **哪些信念被推翻之后，作者后面的论证会立刻失效**

把前提列出来，每条一句话讲清。**只列出来，不展开论证**——前提是否成立不是拆书人要判定的事，能让读者自己看到就够了。

### 第 3 段：作者的思考工具

每个有思想的作者都有一套**专属的思考工具**。可能是几个关键概念的组合、一对对立的区分、一种切入新现象的固定路径，或一种把复杂问题降维的方式。这套工具是作者面对任何问题时的第一反应。

辨认它的三个信号：

- 作者反复使用的核心概念是什么
- 遇到新现象时，作者第一反应往哪儿套
- 作者偏爱的对照、分类、对立项是什么

举几个不同领域的例子：

- **达尔文**（生物学）：变异 / 选择 / 时间累积
- **彼得·德鲁克**（管理学）：知识工作者 / 目标管理 / 顾客创造
- **Andy Grove**（半导体管理）：高产出 / 杠杆动作 / 战略转折点
- **Charlie Munger**（投资）：多元思维模型 / 反向思考 / 能力圈
- **Daniel Kahneman**（心理学）：快思考 / 慢思考 / 锚定 / 损失厌恶

#### 必须列出作者的独占术语

每本好书都有作者**独创或专属**的术语、概念、列表、分类标签。这些东西别的同行没有，是这本书的身份标识。如果一段拆书里没有出现这些独占标签，说明拆的不是"这本书"，是"这个领域"。

举例：

- **凯文·凯利《必然》**：12 个动词（Becoming / Cognifying / Flowing / Screening / Accessing / Sharing / Filtering / Remixing / Interacting / Tracking / Questioning / Beginning）+ technium + protopia
- **马克思《资本论》**：生产关系 / 上层建筑 / 剩余价值 / 阶级斗争
- **Kahneman《思考快与慢》**：System 1 / System 2 / 锚定效应 / 损失厌恶
- **Taleb《反脆弱》**：脆弱性 / 强韧性 / 反脆弱性三态 / 黑天鹅
- **Andy Grove《Only the Paranoid Survive》**：10x 力量 / 战略转折点

**身份检验**：本段独占术语数量少于 3 个 → 拆的不是这本书，是这个领域。回去重读，把作者独占的部分挖出来。

### 第 4 段：作者最后落到哪个判断

不看作者举了多少例子，不看他论证了多少环节。看**合上书之后他要读者带走的那个判断是什么**。通常一两句话讲清。

判断本身要够锋利——能被引用、能被反驳、能在脱离上下文之后仍然成立。

什么样的判断不算数：

- **空话**："X 是复杂的"、"事物都是辩证的"——谁都不会反对的话
- **标签**：只是把书名换个说法
- **过程描述**："作者论证了……"——没说他得出了什么

一句锋利的判断长这样：

- 《Only the Paranoid Survive》："企业的命运不由战略决定，由是否识别和回应战略转折点决定。"
- 《人类简史》："智人胜出不是因为更强，是因为能集体相信虚构的故事。"
- 《Atomic Habits》："你不会上升到目标的高度，只会跌到系统的水平。"

写完看一眼：**这句话单独拿出来读，还有力量吗？**没有 → 软了，重写。

### 第 5 段：值得长期保留的那一件

把整本书烧成灰，能保留下来的那一件东西是什么？十年之后只能记一件事，挑哪一件？

注意：**这一件不是前四段的浓缩**。前四段是"把作者怎么想问题摊开"，这一件是"从整本书最后凝出的那个东西"。

形态五选一，**只挑一种**，不堆叠：

| 形态 | 是什么 | 例 |
|------|--------|------|
| 思考工具 | 一种看世界的固定路径 | 达尔文：变异 + 选择 + 时间 |
| 概念结构 | 一对核心区分或一个结构化工具 | Kahneman：System 1 / System 2 |
| 关键判断 | 一句被作者撬开的真相 | "公司的命运由结构决定，不由战略决定。" |
| 新铸的词 | 作者亲自造的词，进入了行业语汇 | Taleb：反脆弱；海德格尔：Dasein |
| 直引金句 | 作者亲笔写下、可直接引用 | "媒介即讯息。" — McLuhan |

怎么判作者最依赖哪一种：看他反复回到的是哪一类——是一种看问题的方式（思考工具）、一对核心区分（概念结构）、一个被点破的事实（关键判断）、一个他造的新词（新铸的词），还是一句他亲笔写下的话（直引金句）。

**三行交付**：

1. 第一行：形态标签
2. 第二行：内容本体（一句话）
3. 第三行：为什么挑的是这一件

**三道关卡**：

- 十年后只允许记一件事，选的就是这件吗？
- 这一件跟前四段是否重复？重了 → 这是总结，不是内核，重选
- 一个完全没读过这本书的人，听完这一件之后，会不会想去翻原书？会 → 抓到

### 第 6 段：把思考工具搬到新场地

前五段把作者的思考拆开放好，是**理解**。第六段把工具迁移出去，是**掌握**。

理解 vs 掌握的差别：

- **理解** = 能用自己的话讲清楚作者在讲什么
- **掌握** = 在作者没去过的地方，用作者的思考工具自己推一遍，结论站得住

这一段教三个步骤。

#### 步骤一：把思考工具描成一张参考系

回到第 3 段识别出的思考工具。把它从一句话的口号，**描成一个有维度、有方向、有相对距离的空间**。

举例（达尔文）：

- 横轴：时间（一代一代往后）
- 纵轴：环境的选择压力
- 每一个点 = 某物种在某一时刻的所处状态

能说出**轴、方向、关键参考点** → 这就是一个可用的参考系。如果只能说"达尔文讲的是生物进化"，那是标签，不是参考系。

**借成熟参考系最快**：好的类比，本质就是把一张熟悉的参考系平移到一片新的领域。"自然选择就像育种，只不过挑种的人从人换成了环境"——这一句把"育种"这张已经成熟的参考系整张借给了"进化"。

#### 步骤二：把作者的几个核心判断填到参考系里

把作者的核心判断逐个放到参考系的具体位置上。重点不是位置本身，是**位置之间的相对关系**——谁在原点、谁在主轴、谁正对着谁、谁是偏离主轴的特例。

举例（达尔文这套参考系上）：

- **变异**：原点（一切的起点）
- **自然选择**：贯穿纵轴的那把筛子
- **共同祖先**：时间轴最远端的收敛点
- **性选择**：偏离主轴的特例（方向与生存压力相反）

填完之后，看到的不再是孤立的观点列表，是一张相互牵动的图。

#### 步骤三：移到一个新场地，做一次预测

这一步决定第 6 段的成败。**掌握不掌握，全在这一步**。

操作：

1. 在参考系上**挪到一个作者没去过的位置**——最好挨着读者自己熟悉的领域
2. 在新位置上做预测：如果作者本人站在这里，他会用他的工具得出什么结论
3. **预测完之后，回头对一下事实**——猜对了吗

猜对 → 这套工具就是你的了。

举例：把达尔文的"变异 + 选择 + 时间"挪到"想法在人群里怎么传开"这个新场地：

- **变异**：每次转述都会走样一点
- **选择**：好记、合用、能引起共鸣的想法被留下来
- **时间累积**：一代一代往下传

回头对事实：meme 这个概念（Dawkins 提出）正是这样定义的。预测命中 → 这套思考工具已经迁移成功。

#### 为什么"能预测"才算掌握

人脑学会一件事的判定标准，不是能复述，而是**没见过新情况之前已经能猜对**。能用作者的工具预测书外没写过的新事，等于这套工具真的内化成你脑子里的一部分。

### 收尾

走到这里，读者拿到的不是几条记下来的判断，是一套可外推、可预测的思考工具。

下次读一本书的时候，会下意识问三个问题：

1. 作者的思考工具是什么样的？参考系有几个维度？
2. 作者的核心判断在这个参考系的什么位置？
3. 我能不能把这套工具挪到一个新场地，自己推出结论，并且推得对？

三个都能答上来，这本书就拿住了。

## 全文自查（每篇必过）

### 三个核心问题

任何一个答不出 → 没拆到位，回头补：

1. **作者"为什么非要写这本书"？** 不是题目，是具体的痛 / 机会 / 愤怒 / 不满。能 quote 出动机。
2. **作者的独占动作是什么？** 独有、别人没有的概念 / 列表 / 区分 / 视角。能 quote 出具体表述。
3. **作者要读者带走的那一句话是什么？** 锋利到 10 年后还记得。

### 两项关卡（每段写完都过）

- **可替代性测试**：这段拿去描述同领域另一本书还成立吗？成立 → 太抽象，重写
- **独占性检验**：这段有几个只有这本书才有的术语/概念/列表/区分？0 → 拆的是"领域"不是"这本书"；1-3 → 及格；3+ → 好

## 写法

总基调：**冷静、简洁、明快、直接**。

- 不夸作者，不贬作者，不替作者辩护，不替作者道歉
- 走查部分允许节奏舒缓，不许 sales-pitch
- 拆书六段冷、短、直击骨架
- 第 6 段例外，可以热、可以铺开、可以打比方
- 一段连贯散文胜过十个干瘪 bullet
- 短句多、长句少；介词砍（"通过 / 借助 / 凭借 / 在 X 上"能不用就不用）
- 不要"作者论证了 / 作者认为 / X 在第 N 章指出……"——直接说作者干了什么

### 中文写作自查（每段写完扫一遍）

**词汇直译信号**：

| 翻译腔 | 改成 |
|--------|------|
| 让我们一起 X | 我们 X |
| 提供支持 | 撑住 |
| 在情感上 X | 情感上 X |
| 这是必要的 | 必须这样 |
| 做出选择 | 选 |
| 拥有...的能力 | 能 X |
| 进行（研究/讨论） | 直接用具体动词 |
| 通过 X 抓到 Y | X 动词直接带宾 |

**句式信号**：被动句滥用、"是...的"结构、长定语堆叠、"在 X 上"滥用、三层"的"嵌套。

**词性信号**：动名词化、抽象集合名词偏好（"领域 / 阶段 / 过程"）、形容词堆砌、介词链滥用。

**朗读关**：每段默念一遍——读起来卡的地方整句重写。

**自我修辞警告**：不要用元描述式自我吆喝——"这一刀"、"锋利"（当元描述）、"钉死"、"砸实"、"砍掉"、"杀掉"作为段落修辞。内容力度读者自己感受得到，不需要作者预告。

## 怎么找材料

- 只给书名：先 WebSearch / WebFetch 找作者、导言、目录、核心论点的二手解读，拿到核心 argument 再答。不要凭印象瞎拆——印象拆出来是 wikipedia 风的空话。
- 给了 PDF / 内容：直接读。
- 经典书：可靠 LLM 内部知识，但每条都自问"这条是书里实际有的还是我编的"。编的删。

## 红线（每条必过）

1. 走查不能跳章节（可合并相邻章）
2. 走查每章必须有 2-5 条原话金句（作者本人原话，不许复述）
3. 走查每章点评要有立场（软话不要）
4. 不夸、不贬、不替作者辩护
5. 冷静、简洁、明快、直接
6. 第 4 段核心判断不能软（空话不要）
7. 第 2 段前提只列不论证
8. 第 5 段值得长期保留的那一件挑单一形态，三行内交付，不重复前 4 段
9. 零学术腔
10. 避免翻译腔 + 避免自我修辞（自查清单全过一遍）
11. 第 3 段必须列出 ≥ 3 个作者独占术语 / 列表 / 区分（身份检验）
12. 三个核心检验问题必答
13. 可替代性自检 + 身份检验每段过
14. 第 6 段三步必须齐（描参考系 / 填核心判断 / 移到新场地做预测）
15. 输出 Markdown，不要 org-mode
