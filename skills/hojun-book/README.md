# hojun-book

[Claude Code](https://docs.anthropic.com/en/docs/claude-code) 读书技能 — 输入一本书，输出**走查 + 拆书**两份合并交付的 Markdown 文件。

- **走查铺面** — 让你"知道这本书在讲什么"（背景、速读、章节、意义）
- **拆书钻骨** — 让你"看穿作者怎么写这本书"（真问题、前提、工具、判断、内核、外推）

冷静、简洁、明快、直接。零学术腔。

## 安装

```bash
# git clone (推荐)
git clone https://github.com/<your-handle>/hojun-skills.git ~/.claude/plugins/hojun-skills

# 或单文件
mkdir -p ~/.claude/skills/hojun-book
cp skills/hojun-book/SKILL.md ~/.claude/skills/hojun-book/SKILL.md
```

## 使用

在 Claude Code 里说:

```
走查这本书：《国富论》
```

支持的触发：`走查这本书` / `走查 + 拆 X` / `book walkthrough` / `读书笔记 + 拆书` / 直接贴书名。

输出文件路径：`~/Documents/notes/{时间戳}--走查拆书-{书名}__book.md`

## 输出结构

### 一、走查（4 模块）

| 模块 | 内容 |
|------|------|
| 1.1 书籍与作者背景 | 出版时间 / 时代背景 / 作者作品序列位置 / 领域内位置 |
| 1.2 速读总结 | 一句话核心（≤30字）+ 段落速读（200-350字）+ 3 个 takeaways |
| 1.3 章节拆解 | 逐章交付：讲什么 / 关键观点 / **原话金句 2-5 条** / 一句话点评 |
| 1.4 思考与意义 | 重新看什么 / 对谁读 / 能引申到哪 / 配合谁读 |

### 二、拆书（6 段）

| 段 | 内容 |
|---|------|
| 2.1 作者要解决的真问题 | 题面 vs 真问题 + 写作触发（作者为什么是现在、是他来写） |
| 2.2 作者的隐含前提 | 不被讨论但整本书都靠它撑着的那几条立场（只列不论证） |
| 2.3 作者的思考工具 | 含**作者独占术语清单**（≥3 个，否则拆的不是这本书） |
| 2.4 作者最后落到哪个判断 | 锋利、可引、脱离上下文仍成立的那一两句 |
| 2.5 值得长期保留的那一件 | 思考工具 / 概念结构 / 关键判断 / 新铸的词 / 直引金句 **五选一** |
| 2.6 把思考工具搬到新场地 | 描参考系 → 填核心判断 → 移到新位置做一次预测 |

### 三、自查记录

自动附在文末：三个核心问题 / 可替代性测试 / 独占术语数 / 中文写作扫描。

## 红线（每篇必过）

- 走查不跳章节；每章原话金句 2-5 条（**作者本人原话**，不许复述）
- 章节点评要有立场，"讲得很好""很重要"这类软话直接砍
- 拆书第 3 段必须列出 ≥3 个作者独占术语 / 列表 / 区分（**身份检验**）
- 第 4 段判断要锋利（"X 是复杂的""事物都是辩证的"这种谁都不反对的不算数）
- 第 5 段挑**单一形态**，三行交付，不堆叠、不重复前四段
- 第 6 段三步必齐：描参考系 / 填核心判断 / 移到新场地做预测
- 输出 Markdown，不要 org-mode
