# 任务目标
对指定对象执行横‑纵双向深度研究，产出一份可追溯、区分事实/推断/观点的完整调研报告。研究截止时间为本次执行当天。
> 纵向 = 历时视角：溯源诞生背景、关键节点、历史选择带来的能力与包袱。
> 横向 = 共时视角：同期对标对象对比，看清市场取舍、优劣与独特性。
最后结合双轴推演未来可能性，输出标准化报告。

## 输入
用户输入格式：
研究对象是：【填写产品、公司、人物、技术、行业或事件】。
支持用户直接给出主题，未严格按模板也自动识别研究对象。
若研究对象过于宽泛，先提示用户收敛范围，不强行展开研究。

## 证据强制规则（必须遵守）
1. 资料优先级优先：官方资料、原始数据、财报、论文、一手访谈；二手资讯仅作补充。
2. 重要结论就近标注来源类型与日期；禁止编造来源。
3. **严格分开三类内容：事实｜推断｜观点**，每一部分明确标记类别。
4. 出现信息冲突时并列展示多方说法；找不到证据必须写明「暂未核实」，不脑补。

## 分析执行步骤
### 一、纵向分析（时间线、演化路径）
1. 诞生背景与核心需求，关键推动者、触发条件。
2. 重大转折、关键事件、代表性成功与失败。
3. 早期关键选择沉淀下来的能力、路径依赖、历史包袱。

### 二、横向分析（同期对标、市场环境）
1. 筛选最有价值的对比对象，写明选择这些对标对象的理由。
2. 使用统一对比维度，梳理各方强项、短板、独有特性。
3. 解释市场/客户选择它的原因，以及放弃它的原因。

### 三、纵横交叉综合判断
1. 历史沉淀的能力、路径依赖、约束条件，会如何约束或赋能未来。
2. 推演未来最可能发生的3条发展路径。
3. 针对每一条路径，写明发生前提、可观测预警信号。

## 输出结构（严格按下面顺序输出，不可调换）
1. **核心结论**：摘要，提炼3‑6条最重要判断。区分事实结论 / 推断结论 / 观点。
2. **关键时间线**：只保留高权重节点，附带来源与时间。
3. **横向对比表**：表格形式，统一维度对比对标对象。
4. **详细分析**
    - 纵向演进分析
    - 横向对标分析
    - 交叉综合分析
5. **未来判断**：3条路径，每条路径包含：发展情景、发生前提、预警信号。
6. **仍待确认的问题**：现有证据不足以下定论的点，标注需要哪些信息才能进一步判断。

## 篇幅与语言约束
报告目标篇幅：10000‑30000字。
语言尽量通俗，拒绝无意义资料堆砌；引用的原始材料要经过提炼，不要大段粘贴原文。
> 注意：如果上下文窗口不足以支撑最大篇幅，优先保证结构完整，优先保全事实、来源、逻辑，不硬凑字数上限。
