## 目标

把一本书读"透"，输出可反查、可批判、可应用的结构化深度分析。区别于读后感和摘要：

- **不是**主观感受，**是**还原作者立场 + 暴露隐含假设
- **不是**凭印象摘金句，**是**带原文出处可反查
- **不是**情绪化吐槽或一边倒赞美，**是**有理有据找漏洞
- **不是**"读完很有启发"的结论，**是**"能迁移到哪些场景"的具体动作

## 触发方式

用户输入书名即激活：

- `走查《xxx》`
- `拆书《xxx》`
- `拆解《xxx》`
- `深度分析《xxx》`
- `《xxx》本质是什么` / `《xxx》核心观点是什么`

## 报告结构（10 章）

### 第 1 章：一句话本质

讲清作者究竟在主张什么。

写法示例：
> 《穷爸爸富爸爸》的本质：财务自由不是高薪给的，是"让钱替你工作"的资产思维给的——这套思维富人家庭口传心授，穷人家庭从未接触。

### 第 2 章：书籍基本信息 + 影响力 + 目标读者

**2.1 基本信息**
- 作者：姓名、国籍/籍贯、个人背景（行业 / 学派 / 代表性身份）
- 首版：年份 + 原始语言 + 出版社
- 当前主流版本：版次、最新印刷、是否扩充修订
- 译本说明（仅引进版需要）：译者、推荐译本、是否存在知名翻译争议
- 所属系列 / 丛书
- 作者其他代表作

**2.2 影响力**
- 销量与版次：累计销量、覆盖语种数、是否长期重印
- 引用反响：学术 / 行业 / 媒体的被引用频度
- 影响群体：哪些行业、学派、思潮受其影响
- 跨界扩散：是否进入影视改编、教材、政策文件、企业培训
- 同行评价：领域内顶级专家或机构的公开评价

**2.3 目标读者画像**
- 该读者：什么背景 / 什么处境 / 在解决什么问题的人能从中获益
- 前置知识：阅读本书需要什么基础知识或经验
- 不该读者：哪类人读了浪费时间，或者会被误导

### 第 3 章：章节结构 & 论点地图

按作者原序逐章扫描，必须覆盖全书所有章节，不允许跳章。表格输出：

| 章节 | 核心观点（一句话） | 关键证据 / 案例 | ⭐ 主线 |
|---|---|---|---|
| 第 1 章《标题》 | ... | ... | ⭐ |
| 第 2 章《标题》 | ... | ... | |

⭐ 标记规则：跨全书反复出现、构成作者主线论证的章节标⭐；只在局部承担说明 / 案例 / 过渡的章节不标。

扫描每章时三步走：
1. 区分作者陈述 vs 引用他人观点（后者写"作者引述 XX 观点：..."）
2. 用一句话压缩本章作者立场
3. 标关键证据类型（数据 / 案例 / 推理 / 故事 / 引经据典）

### 第 4 章：金句精选

收录能反查的金句，按主题分组：

- **核心立论金句**（直接表达作者主张）
- **方法论金句**（教读者怎么做）
- **警世金句**（揭穿读者盲区）
- **修辞金句**（语言本身有传播力，可选）

每条格式：

> "[金句原文]"
> 出处：第 X 章 / 第 X 页（电子书可注章节段落锚点）
> 注解：[一句话说明为何收录]

无法反查的句子一律不收。

### 第 5 章：立论基础

挖作者**没说出口但贯穿全书**的根基。三问：

1. **作者站在什么传统上？** 师承哪个学派、引用最多的前人作品、用了哪些学派的术语
2. **作者反对谁？** 隐含的假想敌、哪些章节明显是"反驳什么"而不是"建立什么"
3. **哪些假设没说出口但贯穿全书？** 作者把什么当成"显而易见的事实"、去掉这些假设全书还能不能成立

### 第 6 章：方法论 / 思维工具

从书中拆出**可以离开本书单独使用**的分析框架或概念工具。每条要求：

- **名字**：作者怎么命名的（如"第二曲线"、"反脆弱"、"心流"）
- **本质**：2-3 句话说清这个工具解决什么问题
- **使用条件**：什么场景能用、什么场景不能用
- **可迁移性评分**：高 / 中 / 低 + 一句话理由

只收**真正能拆下来复用**的工具，纯描述性概念不收。

### 第 7 章：批判性审视

**有理有据**找漏洞，没有就**不写**——禁止为了凑章节瞎编漏洞。三个角度可挖：

1. **论证最薄弱的地方**：哪一章 / 哪一节的推理跳跃最明显？哪些"显然"其实不显然？
2. **cherry-picking 嫌疑**：作者举的案例是系统抽样还是挑出来支持结论的？反例在哪？
3. **时代局限 / 文化盲区**：本书写作时的时代条件（经济周期 / 技术阶段 / 社会风潮）今天是否还成立？作者的文化背景产生了哪些视角盲区？

每条**必须给具体例子 + 引用原书章节定位**，否则不写。

### 第 8 章：整书观点综合

把全书压缩成一段**完整、连贯**的论述——像作者亲口跟读者从头讲一遍他想说的全部。要求：

- 300-600 字
- 必须包含：作者的起点观察 → 核心问题 → 关键论证 → 主要结论 → 给读者的最终建议
- 不分点、不列表，一段话写完

读者读完这一段，应当不读全书也能基本把握作者全貌。

### 第 9 章：读者精华 & 迁移建议

**a. 最值得拿走的 3-5 条精华**（按重要性排序）

每条格式："[一句话观点]——出自第 X 章"

**b. 三条具体应用场景**

每条要回答：
- 在什么场景下用这个精华？
- 具体怎么做？
- 多久能验证有没有效？

**c. 各自的失效边界**

每条对应的应用场景下，**什么条件下这条精华会失效或反噬**？

### 第 10 章：横向对照书单

帮读者判断"读这本还是读那本"。三类按"有就给、没有就略"原则填，不要求数量。每条必须给出**具体书名 + 一句话推荐理由**，禁止写"还有很多类似的书"这种敷衍语：

**Read-also（同议题更深的延伸阅读）**
- 书名 · 作者 · 一句话推荐理由（为什么读完这本可以再读这一本）

**Read-instead（如果不读这本可以读什么）**
- 书名 · 作者 · 一句话推荐理由（为什么这本可能比本书更适合某类读者）

**反方向阅读（立场对立、能形成对话的）**
- 书名 · 作者 · 一句话推荐理由（它如何挑战或反驳本书的核心立场）

## 硬约束

1. 金句必带原文出处，无法反查的不允许写
2. 第 7 章漏洞必须有理有据 + 引用原书章节定位，没有就不写，禁止为凑章节瞎编
3. 不能用二手书评 / 摘要 / 读书会笔记冒充原文金句
4. 不能输出"读完很有启发"、"值得一读"、"经典之作"这类无信息量句子
5. 任何无法核实的具体数据（销量、引用次数、获奖记录）**标注"未核实"或直接不写**，禁止编造
