## 目标
把一本书读"透"，重点是**学习与应用** — 在客观、批判性地理解全书的基础上，提炼可迁移的方法与观点。不是读后感、不是摘要、不是凭印象的吐槽或赞美。

## 报告结构（9 章）

### 第 1 章：本书速览
一段**连贯论述**（不分点不列表），让读者快速看懂这本书 — 它在讲什么、作者的核心观点是什么、解决了什么问题。读完这段能基本把握作者全貌。

### 第 2 章：书籍基本信息 + 影响力
**2.1 基本信息**：作者背景 / 首版（年份+语言+出版社）/ 当前主流版本 / 译本说明（仅引进版）/ 所属系列 / 作者其他代表作
**2.2 影响力**：销量与版次 / 引用反响 / 影响群体 / 跨界扩散 / 同行评价

### 第 3 章：章节结构 & 核心内容
按原书章节顺序扫描，**全书章节必须全覆盖，不允许跳章**。每章用段落形式写：

> **第 N 章《标题》**
> **核心内容**：这一章在讲什么 — 话题、关键概念、主要案例（50-200 字）
> **核心观点**：作者在这章想让你接受什么 — 原文里的主张或结论

**禁止**：评价词 / 论证脉络 / 章节关系 / 延伸对比 / 抄目录 / 凑字数。

### 第 4 章：立论基础
**4.1 作者明面的主张**
- **核心观点**：本书最浓缩的几条主张是什么
- **希望读者理解什么**：读完后应建立什么新认知 / 新视角
- **希望读者做出哪些变化**：作者希望读者改变哪些具体行为、决策或习惯

**4.2 作者没说出口但贯穿全书的根基**
1. 作者站在什么传统上？（师承 / 引用源头 / 学派术语）
2. 作者反对谁？（隐含的假想敌、反驳对象）
3. 哪些假设没说出口但贯穿全书？（从案例 / 术语 / 价值倾向反推 — 去掉这些假设全书还能不能成立）

### 第 5 章：金句精选
按主题分组：核心立论 / 方法论 / 警世 / 修辞（可选）。每条格式：
> "[金句原文]"
> 出处：第 X 章 / 第 X 页
> 注解：一句话说明为何收录（优先关联立论 / 方法论）

### 第 6 章：方法论 / 思维工具
拆出**可离开本书单独使用**的工具，每条包含：名字（作者命名）/ 本质（2-3 句说清解决什么问题）/ 使用条件（能用 / 不能用的场景）/ 可迁移性（高 / 中 / 低 + 一句话理由）。

*仅解释"是什么"、无落地步骤的纯描述性概念不收。*

### 第 7 章：批判性审视
有理有据地找漏洞，从三个角度（每条含章节定位 + 具体例子）：
1. **论证最薄弱的地方**：推理跳跃
2. **案例挑选偏差**：案例是系统抽样还是挑出来支持结论的；附反例
3. **时代局限 / 文化盲区**：时代或文化背景的变化

某个角度确实没找到就不写。

### 第 8 章：核心精华、启发与迁移应用
- **3-5 条核心精华**（按重要性排序）：[一句话观点]——出自第 X 章
- **启发与思考**：这些精华激发什么深层反思 / 新视角 / 自我审视（认知层）
- **如何用起来**：每条精华 + 第 6 章每个工具，配一个应用示例，写清「场景 + 具体怎么做 + 多久能验证有没有效」（行为层）
- **什么时候不要用**：每条说明失效条件 + 理由

### 第 9 章：横向对照书单
有就给、没有就不写。每条格式：书名 · 作者 · 一句话推荐理由（关联本书核心 / 漏洞 / 立场）。
- **Read-also**：同议题更深的延伸阅读
- **Read-instead**：替代选择
- **反方向阅读**：立场对立的对话类书籍

## 硬约束
1. 金句必带原文出处，无法反查不写；不用二手资料冒充原文
2. 不输出"值得一读"这类无信息量的评价句
3. 无法核实的数据不写，禁止编造
